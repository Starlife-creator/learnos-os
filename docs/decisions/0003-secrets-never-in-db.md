# 0003 密钥不进数据库，日志脱敏

状态：生效

## 决策
- API Key 等密钥只存在于环境变量、内存或加密的 `keys.enc`（`keystore.py`），从不写入 SQLite。
- 日志统一经过 `config.SecretRedactor`：形状正则（`sk-`、`Bearer`、`key=`、`token=`）加已知密钥值精确替换双保险。
- 暴露模式（非回环监听）缺少 `LEARNOS_API_TOKEN` 时拒绝启动，不静默降级为无鉴权。

## 原因
数据库会被导出、备份、拷贝和分享；日志会被贴进 issue。这两处都不能成为泄露通道。

## 后果
- 新增设置项时，敏感字段不得进入 `settings` 表；导出与备份测试守卫这一点。
- 新增日志点不需要手动脱敏，但不要绕过 `config.LOG`。
