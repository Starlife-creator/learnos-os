# 0001 零第三方依赖、本地优先、工作区隔离

状态：生效

## 决策
- 主路径只用 Python 标准库（`http.server` + `sqlite3`）与原生 HTML/CSS/JS，无构建步骤。
- 可选能力（FSRS vendor、OCR、向量检索等）缺失时必须有降级路径，不能让主流程不可用。
- 所有数据、日志、运行与测试产物限制在项目目录内。

## 原因
定位是「个人学习终端」：单用户、离线可用、双击即启动、可整体拷走。依赖越少，长期可维护性越高，打包（PyInstaller 单文件）越稳定。

## 后果
- 新功能先问能否用标准库实现；必须引入时放在可选分支并写降级测试。
- 前端模块化只考虑原生 ES modules，不引入打包器。
