# 0004 掌握度变更事件溯源，单一写入口

状态：生效（收敛进行中）

## 决策
- 掌握度每一次变化都写一条 `mastery_events`（来源、旧值、新值、原因），与状态更新在同一事务内完成。
- 所有写入经由单一入口函数，禁止在业务代码中直接 `UPDATE ... SET mastery`。

## 原因
趋势图、撤销、错因诊断、熟悉度展示与后续的北极星指标（实际保持率）都依赖完整的变更历史。多入口直写会让事件日志残缺，用户手动修改与算法结果也无法区分。

## 现状
v34 已建表，但截至 2026-10 只有 `graph.py` 的少数路径写事件；复习、题库、错题编辑、报表、试卷等仍直写。收敛与守卫测试列在优化路线阶段 2。

## 后果
新增掌握度相关逻辑一律调用统一入口；守卫测试落地后，直写会让测试失败。
