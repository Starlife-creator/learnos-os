# 0011 北极星指标：实际保持率 vs 目标保持率的校准缺口

状态：生效

## 决策

本项目的北极星指标不是「每天复习多少题」或「连续打卡多少天」，而是：

> **校准缺口 = 实际保持率 − 目标保持率**

- 目标保持率取自 FSRS 的 `desired_retention`（默认 0.9，可按学科设置）。
- 实际保持率只统计**有前次复习记录**的复习（`review_log` 里同一项的上一条）：
  首次接触一道题/一张卡不算「保持」。样本来源见 ADR 0013（题目与闪卡同权）。
- 按 `due_date`（预期间隔）与相邻两次复习的间隔对比，把样本分为**按时**与**逾期**
  两组，两组分别报告，不混成一个数。
- 另报「成熟题占比」（`repetition >= 3`）作为结构性健康指标。
- 样本 < 20 一律返回 `insufficient`，只给数字不给结论；缺口 > +8pp 为
  `conservative`，< −8pp 为 `aggressive`，其余为 `calibrated`。

实现是纯读视图：`reports.py::north_star()`，HTTP 入口
`GET /api/report/north-star?days=30`，前端在周期报告弹窗的第三个 tab「记忆校准」。

## 原因

1. **投入类指标会被刷，且不可反推参数**。「今日复习 50 题」很容易靠机械点击达成，
   却完全不说明记住了没有；它也无法回答「间隔该不该调长」。
2. **绝对保持率没有方向**。保持率 100% 也可能意味着每天在重复已经会的东西 ——
   分母是「发生过复习的记忆」，不是「该记住的东西」。所以指标必须是**自参照**的：
   拿实际结果和 FSRS 自己的预测比。
3. **不需要新表**。`reviews` 已经记录了每次复习的 `interval_days`、`due_date`、
   `result`、`created_at`，足以复原「当时预期间隔 vs 实际间隔 vs 结果」这三要素。
   这是选择「相对目标」而非「相对历史预测值」的直接原因：`reviews` 没有保存
   当时的 FSRS 状态快照，历史 `R` 无法复算。
4. **逾期样本要单独看**。逾期后仍答对，说明记忆比模型预估的更牢（模型偏保守）；
   逾期后答错，说明间隔超了。混在一起会让两种相反的信息互相抵消。

## 后果

- 这是一个**可证伪的调参回路**：缺口持续为正 → 间隔偏短、可拉长；持续为负 →
  当前节奏超过了实际时间预算，应先减新题量而不是继续加复习。
- 口径写在 `reports.py` 一处，`tests/test_north_star.py` 直接断言
  「首次接触不计入」「窗口外的复习仍算作窗口内首条的『前次』」「按时/逾期分开」
  「样本不足不给结论」。
- 已知局限（刻意保留，不假装解决）：目标是**单一全局参数**，不是逐题预测。
  若要精确校准，需要给 `reviews` 增列当时的 `predicted_retention`，那是写入路径
  的改动，单独决策（尚未做）。
- ADR 0004 的掌握度事件表提供了另一条口径（`item_type='problem'` 的等级变化），
  但那条链路是**自评与编辑驱动**的，不适合当作记忆保持的证据；北极星仍以
  复习记录为准。
