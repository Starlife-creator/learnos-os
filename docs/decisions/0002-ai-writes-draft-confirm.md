# 0002 AI 写入走草稿确认或结构化校验

状态：生效

## 决策
AI 产出（制卡、出题、资料抽取、错因诊断、口试判分）不直接落库。两种合法路径：
1. 草稿确认：生成草稿 → 用户预览/编辑 → 显式确认后写入。
2. 结构化校验：输出经 `validate.py` 等按 schema 校验、裁剪、封顶后才写入，且来源可追溯。

## 原因
LLM 会胡说。个人学习数据一旦被错误内容污染，复习调度和掌握度会持续放大错误，且用户难以察觉。

## 后果
- 新增 AI 写路径必须说明属于哪一种，并有对应测试。
- 检索无命中时宁可弃答（见 OPTIMIZATION_PLAN X1），不编造。
