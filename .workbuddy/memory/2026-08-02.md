## 第二轮优化（15项全部完成）

### P0 修复
1. **hint 泄露修复**: handler.py hint fallback 不再拼接 `exc` 到返回内容，改为只记日志
2. **.gitignore 修复**: 添加 `!build.spec` 例外，确保构建脚本被版本控制跟踪
3. **端口冲突检测**: app.py 兼容 Windows errno 10048 + 中文错误消息

### P1 修复
4. **响应式 CSS**: index.html 添加 `@media (max-width: 640px)` 断点，移动端栅格塌缩为单列
5. **LaTeX 渲染**: 引入 KaTeX CDN，`renderMath()` 在 DOM 更新后渲染 `$...$` 和 `$$...$$`
6. **死文件清理**: 删除 static/app.js 和 static/styles.css（旧版前端残留）
7. **分页 API**: `/api/problems` 支持 `?page=1&limit=50`，返回 `{items, total, page, pages}`
8. **测试隔离**: 每个测试类使用独立 DB 文件名 + 端口 0 自动分配
9. **DELETE 404 检查**: `do_DELETE` 检查 `cursor.rowcount`，删除不存在行返回 404

### P2 修复
10. **版本化迁移**: db.py 引入 `schema_version` 表，支持扩展式版本迁移
11. **设置缓存**: ai.py 添加 30 秒 TTL 的 `get_cached_settings()`，设置更新时自动失效
12. **键盘可访问性**: Esc 关闭弹窗 + 点击遮罩关闭
13. **PORT 容错**: config.py 捕获 `ValueError`，无效端口回退默认 8765
14. **口试结束端点**: `POST /api/oral/{id}/end` 关闭会话，前端 `resetOral()` 调用
15. **README 重写**: 106 行完整文档，覆盖功能/快速开始/配置/结构/测试/构建
