功能帮助

    

      
LearnOS 是本地优先的个人学习系统：记录尝试 → 分级提示 → 主动回忆 → 间隔复习 → 口试检验。所有数据保存在本机数据库，不依赖云端；AI 为可选增强，未配置时各模块自动降级。

    

    

      
快速上手（五步学习循环）

      
① 「设置」页配置 AI 接口（OpenAI 兼容，本地 Ollama 亦可）→ ② 「题库」练习或「错题」页录入错题 → ③ 「复习」页按时复习并评分 → ④ 「口试」检验真正理解 → ⑤ 「概览」页跟踪趋势与薄弱点。建议每天从「概览」的今日行动开始。

    

    

      
概览与今日行动

      
展示待复习数、掌握度、未来 7 天复习压力、记忆保持曲线与错因分布。今日行动是统一学习队列：到期复习 → 薄弱概念口试 → 错题巩固 → 题库练习，按优先级逐项推进。顽固错题（重复出错 ≥2 次）单独列出。全局搜索：Ctrl+K 跨错题/概念/题库/资料直达。

    

    

      
题库练习

      
按学科/单元选择题目练习，作答即时判定对错并记录。答错的题可一键转入错题簿（带题干与解析）；题库状态分三种：未做 / 已入错题 / 最近答对。支持 JSON 批量导入自选题，也支持用「资料导入向导」从教材自动提取例题。

    

    

      
错题管理

      
录入错题时填写：题目、自己的尝试、错误类型、陷阱笔记——「错在哪里」比答案更有价值。支持拍照上传，AI 识别生成草稿（需 vision 模型），确认后才保存。

      
四级提示逐步引导：1 概念检查（只指出方向）→ 2 解题方向 → 3 解题框架 → 4 完整解析（附「自己重做一遍」引导）。上次复习失败时一级提示会附加诊断建议。「举一反三」可生成 3 道变式题，草稿确认后保存；AI 打标签同样是草稿确认制。列表支持卡片/表格两种视图（表格可按任意列排序）与保存的筛选器（组合条件起名保存、一键切换）。

    

    

      
间隔复习

      
默认 FSRS-6 算法（内置实现，不可用时自动降级 SM-2），在最佳遗忘点安排复习。回忆后按四档评分：忘记 / 模糊 / 想起 / 秒答——评分越诚实，调度越准。队列按优先级排序：逾期久 > 掌握度低 > 带漏点，同知识点自动交错；可在设置中设每日上限防止爆量。逾期复习按间隔减半顺延；「估算最优保持率」会基于你的卡量模拟工作量/记忆量平衡给出推荐值，样本够多还可训练个人化参数。

    

    

      
口试与费曼自评

      
选一个知识点，AI 五轮追问层层深入，检验能否用自己的话讲清概念。口试与提示会自动注入学习者画像（薄弱点/高频错因/目标），追问方向动态偏向你的薄弱区。口试结束后可让 AI 生成口述卡片草稿存入错题。费曼模式配合自评表使用：先自己讲，再对照评分。

    

    

      
知识图谱

      
独立页（更多 ▾ → 图谱）可视化概念层级、先修关系与掌握度：绿=已掌握、黄=学习中、红=薄弱。概念支持设置别名（如 N2L = 牛顿第二定律）。错题页的「未链接提及」会自动扫描错题文本中出现但未绑定的概念（含别名），一键确认绑定，让掌握度统计更准。概念可手动增删。

    

    

      
教材库（RAG）

      
把工作区内的教材/课件/笔记（md/txt/pdf）摄取进资料库后，AI 提示与解答会自动引用你的资料片段（来源可点开）。支持 BM25/FTS5 搜索；删除可撤销。扫描版试卷可用 OCR 卡片提取文本。

    

    

      
资料导入向导

      
教材库页顶部。上传 md/txt 文件（最大 8MB）或选已摄取文档 → 勾选目标（概念图谱 / 例题入题库 / 识别为试卷）→ AI 提取草稿 → 逐项勾选确认 → 导入。分段大小按你设置的模型上下文自适应，超长文本自动分段全覆盖（预计调用次数多时会先确认）。全程草稿预览不静默落库；未配置 AI 时按标题层级降级提取概念。

    

    

      
考试就绪度

      
录入你的真题试卷（或用导入向导整卷识别），把题目关联到错题，系统按知识点统计该卷的就绪度：绿 ≥80% / 黄 ≥60% / 红 <60%，并给出优先补弱清单。

    

    

      
学科管理

      
右上角切换当前学科，图谱/题库/错题/复习全部按学科隔离。设置页「学科管理」可新增自建学科（支持中文显示名）或删除空学科；内置物理/化学/数学不可删。放入 data/seed_concepts_<id>.json 可为新学科预置概念图谱。

    

    

      
AI 配置与隐私

      
设置页填写 OpenAI 兼容接口（api_base / key / 模型，可分 fast 轻量与 heavy 推理档）。API Key 绝不写入数据库：优先环境变量，其次 AES-GCM 加密密钥库（主密码），再次会话内存；日志自动脱敏。AI 未配置或失败时：提示降级为本地模板、变式降级离线生成、识别降级附件模式——主流程始终可用。

    

    

      
数据备份与导出

      
概览页「导出数据」生成 JSON（题目+提示+复习记录）；导入前自动备份数据库。每天首次运行自动备份到 backups/（保留 7 份）。数据库为本机 learnos.db，可随时复制迁移。

          ❓ 这些 AI 设置都是什么意思？怎么用？
          

            
① API 地址（api_base）：你的 AI 服务提供商给的接口地址，形如
            https://api.deepseek.com/v1、https://api.openai.com/v1、
            阿里云百炼 https://{工作空间}.maas.aliyuncs.com/compatible-mode/v1。
            不知道就联系你购买的模型平台，或看官方文档「base_url」。

            
② API 密钥（api_key）：你在模型平台创建的密钥，形如 sk-xxxx。
            这是你付费/免费额度的凭证，保存到本机文件加密存储，不会写入数据库，也不会随学习数据共享。

            
③ 模型名称（默认 / 轻量 fast / 推理 heavy / 视觉 vision）：LearnOS 按任务轻重把 AI 调用分
            4 个档位，可分别配不同模型（同平台内更便宜/更快的用轻量，更强的用推理）：
            
    
              
  • 默认模型：兜底档，其余档位留空时用它。
    • 
              
  • fast（轻量）：处理提示词、标签提取、断句分段等短小快速的任务。
                用便宜快速的模型（如 deepseek-chat / qwen-turbo / gpt-4o-mini），省钱省时。
    • 
              
  • heavy（推理）：处理变式题、苏格拉底追问、AI 出题/审题/评分、资料提取等
                复杂任务。用强模型（如 deepseek-reasoner / qwen-max / gpt-5），质量更高。
    • 
              
  • vision（视觉）：拍照/截图识别题目专用，需选支持图片输入的模型
                （如 qwen-vl-max / gpt-4o）。不配则拍照题只存图不识别。
    • 
            

            四个档位可都填同一模型（最省心），也可按性价比分开配。

            
④ Temperature（温度）：控制回答的随机性/创造性。
            取值 0~2：越接近 0 回答越保守、确定（适合评分、出题、提取等"要准确"的任务，推荐 0.3 以下）；
            越接近 1~2 越有创意、发散（适合头脑风暴、写作润色）。默认 0.3 已适配大多数学习场景，
            除非你发现 AI 回答太教条（可调高）或太飘（可调低），一般不用动。

            
⑤ 上下文窗口（决定分批大小）：你的模型最长能"一次记住"多少 token。
            填得越大，资料导入时分段越大（8k≈4k字/段，32k≈16k字/段，128k+≈12k字封顶）。
            填错的影响：填得比模型实际能力大，超大分段可能触发模型报错或质量下降；
            填得小则分段碎、调用次数多。请按你模型官方标注的上下文长度填。

            
⑥ 关闭思考模式：reasoner 类模型（deepseek-reasoner / kimi-k2 / GLM 深度思考等）
            默认会先"内心推理"再回答。对"提取 JSON、打分、出题"这类结构化任务，推理既拖慢又可能
            只返回推理内容导致解析失败，建议关闭。想用流式对话深度推理时再打开。

            
⑦ 单次输出上限（max tokens）：限制模型单次回答的最长 token 数。
            设太小 → 长文提取/长答案被截断（你会看到"内容被截断"类的报错）；
            设太大 → 超出模型支持上限报 400。默认 4096，一般够用；批量提取大量概念时可提到 8192。

            
⑧ 缓存 AI 提示：相同题目重复问"提示"时不重复调用 AI（直接返上次结果），省额度。
            适合反复刷同一道题；关闭则每次重新生成。

            
⑨ 允许本地/内网端点：开启后才能连接 Ollama、vLLM 等本机/内网自建模型服务。
            仅在本机使用时建议开启。

            
⑩ 主口令：给密钥文件加密的独立密码。设置后密钥以密文存盘，重启/换机需输入口令解锁。
            忘记口令无法找回密钥，请牢记。

            
⑪ 智能分段（资料导入自动生效）：导入长资料时，LearnOS 会先用轻量模型
            （fast 档）判断每批的合适断点，让批次落在语义完整的句子/段落处（而不是机械切字），
            提取质量更高、更少截断。这一过程无需你配置，也会自动把极端内容拆小块重试。

            

            常见问题：
            「测试连接成功但提取失败」→ 看下方 ②是否保存了密钥、⑥思考模式是否开启（建议关）、
            ⑦输出上限是否太小（建议 4096+）；
            「提示一直排队/很慢」→ 换更快的 fast 模型，或把 ⑤上下文窗口调小减少单批长度；
            「AI 答非所问」→ 把 ④温度调低到 0.2 以下试试。
